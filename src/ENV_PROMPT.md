You can create images, videos and music using aigc_create. First read capabilities; only explicitly configured providers are available. Read aigc_help for creative prompting and reference roles.

Use the read-only aigc_query for capabilities, status, list, inputs, read and cancellable wait. Completion notices contain artifact ids and metadata; read explicitly retrieves media. Creation and cancellation remain actions. Provider capabilities list supported parameter keys; do not assume an ignored parameter took effect.

Persona owns identity, known people, memory and artistic choices. If appearance_lookup is provided by Persona, select confirmed identity references there and pass their handles/revisions explicitly. The AIGC World does not inspect memory, other World files, ports or game state.

For an enhanced game photo, ask the game World for an ordinary screenshot plus historical scene/camera evidence, optionally a voxel proxy. Pass the chosen scene as reference 1 and identity references after it. Preserve the requested landmarks, action and camera; choose the composition and style yourself. Ordinary photography remains a game capability without a model. Original creations need no game.

Accepted is not completed. Use original job ids and status/read/wait or aigc.job events, then inspect the actual artifact before adoption. inputs retrieves raw prompts and original references. Preserve originals; distinguish observed facts from invented details. Creation does not publish or play anything. Use the relevant chat/performance World for that after choosing the finished result. Cancel waiting separately from cancelling a job; local cancellation does not prove remote work stopped.

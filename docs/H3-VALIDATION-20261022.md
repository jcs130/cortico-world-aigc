## 成片与速度

每个样本完整解码为 960×544、24FPS、124 帧、约 5.167 秒；H.264 视频和 AAC/32kHz/双声道音轨。

| 场景 | 步数 | 供应商执行 | 请求至文件回传 |
|---|---:|---:|---:|
| 一张角色设定参考图，与 Drama3 共用 GPU、显式保留 23GB | 4 | 120.17 秒 | 123.23 秒 |
| 无参考图文生视频，同一受限显存配置 | 8 | 134.25 秒 | 138.24 秒 |
| 同一角色参考、同一 seed，Drama3 停用、独立测试实例保留 3GB | 4 | 95.43 秒 | 99.23 秒 |

第三项与第一项的采样阶段分别约 13.24 秒、74.35 秒。整段差距小于采样差距，
因为模型加载、文本编码和解码仍有开销；不能把采样约 5.6 倍的差异写成端到端提速。
角色样本抽查了转身与挥手过程，外观基本连贯，无设定图排版残留。
音轨已解码且非静音，但没有据此认定听感、对白或固定歌手音色通过。

共享角色样本期间，该 GPU 总显存峰值为 31354MiB，包含其他常驻进程；该数值不是 H3 独占占用。
一组输入和 seed 不能代表广泛画质排名、平均速度或长期直播稳定性。
20 步 quality 档已通过契约与离线验证，本轮没有生成完整步数画质对照。

## Windows 加载和运行边界

最初两次短片尝试在动态加载或显存换页过程中发生原生访问冲突，保留 unknown 任务与错误日志，未自动重投。
成功组合显式使用 `--disable-dynamic-vram --disable-async-offload --disable-pinned-memory`，
并按其他常驻模型预留显存。共享模式仅约 2.4GB DiT 权重留在 GPU，其余卸载；独立模式 DiT 完整加载。
未修改其他 ComfyUI 服务和游戏连接。

现役宿主经已有 gateway 协议热改视频入口，其他 World 配置保持不变。原 rc.1 宿主仍使用原适配器；
深层原始 H3 证据可按网关原任务号查询。rc.2 的 SDK 新增有界原生证据传递，待宿主升级后使用。
任务受理和文件生成均不代表目标完成、作品采纳或播放成功。

临时测试实例与生产入口分离，测试后退出；推理服务没有自动重启或端口扫描。
